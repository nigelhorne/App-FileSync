   22: =head1 DESCRIPTION
   23: 
   24: B::Hooks::EndOfScope 0.28 releases its XS scope hook with an access violation
   25: (0xC0000005) on Perl 5.42 for Windows, after a command has done its work but
   26: before the interpreter exits, so a run that synced everything would still exit
   27: nonzero.  Its plain-Perl hook does not fault.  The implementation is fixed when
   28: B::Hooks::EndOfScope first loads, so this module makes the choice in a BEGIN
   29: block and is the first thing every App::FileSync module loads.
