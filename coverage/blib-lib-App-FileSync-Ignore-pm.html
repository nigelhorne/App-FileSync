=head1 NAME

App::FileSync::Ignore - .gitignore-style path exclusion

=head1 SYNOPSIS

        my $ignore = App::FileSync::Ignore->new(patterns => [ '*.tmp', '!keep.tmp', 'build/' ]);
        print "skip\n" if $ignore->match('src/a.tmp');

=head1 DESCRIPTION

Patterns follow .gitignore: C<*> matches within one component, C<**/>
matches any number of directories, C<?> one character, a leading C<!>
re-includes, a leading C</> anchors at the root, and a pattern without a slash
matches at any depth.  Later patterns win.  A path inside an ignored directory
is ignored.

=head1 METHODS

Args: C<patterns> (arrayref of strings; undefined entries, blanks and comments
are skipped), C<case_insensitive> (boolean).

Returns: an C<App::FileSync::Ignore> object.

Side Effects: none.  The caller's list is not modified.

Usage:

        my $ignore = App::FileSync::Ignore->new(patterns => $config->{ignore});

198# Entry:       $pattern has had its "!" and surrounding blanks removed.
199# Exit:        returns the regex source (not anchored; new() anchors it).
200# Side effects: none.  Hand-written rather than Text::Glob, which has no
201#              "**" and no "slash-less pattern matches at any depth" rule.
202sub _glob_to_re :Private {
203        my ($pattern) = @_;
204
205        # A leading slash anchors; a trailing one (.gitignore's directory marker)
206        # does not, so "build/" matches "build" at any depth as git users expect.
207        $pattern =~ s{/\z}{};
208        my $anchored = $pattern =~ s{\A/}{} ? 1 : 0;
209        my $has_slash = $pattern =~ m{/} ? 1 : 0;

211        # Translate token by token: "**/" any directories, "**" anything, "*"
212        # within a component, "?" one character, everything else literally.

218                        $re .= '.*';
