8# rsync-style block matching.  The receiver describes the file it already has as
9# one strong hash per fixed-size block; the sender scans the new file with a
10# rolling checksum and emits either a copy of a block the receiver already has
11# or the literal bytes that changed.
12#
13# The scanner is pure Perl, so it is deliberately bounded: only files of at
14# least $MIN_SIZE are worth a signature, and at most $SCAN_LIMIT bytes per file
15# are examined for matches.  Whatever lies beyond that is sent literally, which
16# is still correct, just not smaller.  A small edit in a large file is cheap
17# because the unchanged leading blocks are matched without scanning.
18our $MIN_SIZE   = 65_536;
19our $BLOCK      = 16_384;
20our $MAX_BLOCKS = 4_096;
21our $SCAN_LIMIT = 8 * 1024 * 1024;
22our $LITERAL    = 262_144;
